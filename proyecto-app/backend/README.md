# Backend (Express + TypeScript + Sequelize)

API separada de la UI.

## Stack

- Express
- TypeScript
- Sequelize
- MySQL

## Variables de entorno

Se leen desde el archivo `.env` de la raiz del proyecto.

Variables usadas:

- `BACKEND_PORT`
- `FRONTEND_URL`
- `MYSQL_ADDON_URI`

## Scripts

```bash
npm run dev
npm run build
npm run start
npm run db:migrate
npm run db:migrate:undo
npm run db:seed
```
